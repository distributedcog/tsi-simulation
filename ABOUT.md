# About

This repository contains the minimal reproducible simulation code for the TSI paper benchmark.

The benchmark tests whether a registered higher-order additive primitive gives an operational advantage on a task whose obstruction is predicted by the sheaf model. The main ablation preserves the complete pairwise 1-skeleton and removes the higher-order primitive, so the comparison isolates the higher-order operation rather than a change in pairwise topology.

Repository: `distributedcog/tsi-simulation`
